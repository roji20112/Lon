DZ AUTO — نسخة أولية قابلة للتثبيت على iPhone وAndroid

مهم:
- هذه نسخة PWA (تطبيق ويب قابل للتثبيت)، وليست ملف APK أصلياً أو تطبيقاً منشوراً في App Store.
- المنتجات في هذه النسخة تُحفظ محلياً في المتصفح على نفس الجهاز. حتى الآن لا يراها كل المستخدمين.
- زر واتساب يفتح محادثة البائع. أرقام العرض تجريبية؛ استبدلها بأرقام حقيقية بموافقة أصحابها.

النشر المجاني على GitHub Pages:
1) افتح https://github.com وسجّل الدخول.
2) أنشئ مستودعاً جديداً باسم dz-auto واجعله Public.
3) ارفع جميع الملفات الموجودة في هذا المجلد إلى المستودع (index.html, style.css, app.js, manifest.json, sw.js).
4) من Settings > Pages اختر Deploy from a branch.
5) اختر Branch: main والمجلد /(root)، ثم Save.
6) بعد النشر افتح الرابط الذي يعطيك GitHub Pages.

التثبيت:
- Android: افتح الرابط في Chrome ثم القائمة ⋮ > Install app أو Add to Home screen.
- iPhone: افتح الرابط في Safari > زر المشاركة > Add to Home Screen.

ربط Google Sheets (الخطوة التالية):
هذه النسخة لا تتصل بجداول Google تلقائياً. لعمل سوق مشترك بين جميع البائعين والمشترين نحتاج نشر Google Apps Script كواجهة API وربطه بالتطبيق، مع تخزين صور المنتجات في خدمة صور مناسبة. لا تضع مفاتيح سرية داخل ملفات الواجهة.

التطوير المطلوب قبل إطلاق حقيقي:
- إضافة قاعدة بيانات مشتركة وتسجيل دخول آمن.
- مراجعة إعلانات البائعين ومنع الاحتيال.
- رفع صور حقيقي، وإدارة الطلبات، وشروط استخدام وسياسة خصوصية.
- لا تدفع أو ترسل بيانات حساسة قبل التحقق من البائع والمنتج.
